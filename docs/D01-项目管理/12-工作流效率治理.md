# 工作流效率治理

## 测量基线与原因

`60bf5c0` 最终代码全量复验：845 passed、1 skipped，563.62 秒。
两组验收专项：69 passed，106.71 秒。专项已包含于全量，不把二者当作两份互不相交的覆盖。
该轮看板从领取到完成约 72 分钟，包含开发约 19 分钟、首次审查约 29 分钟、返修约 2 分钟、复审约 7 分钟及 QA 约 14 分钟。看板时间是墙钟时间，不等于模型思考或 CPU 时间。

慢用例主要涉及 Runner、Git 工作区和跨进程恢复；它们具有必要的集成覆盖，不能靠删除反例或跳过安全门禁加速。
当前不把未知的模型排队、上下文阅读时间当成已测量事实，也不承诺全流程固定缩短百分比。

## 执行分工

| 时点 | 执行方 | 检查 |
| --- | --- | --- |
| 开发与返修 | Builder | 缺陷反例、影响回归 |
| 提审 | 独立 Reviewer | 固定候选 diff、安全扫描、实际调用链，不兼任 QA |
| 冻结准出 | 原生 QA 或托管 Runner | 一次契约要求的完整检查及独立质量判断 |
| 最终验收 | 有授权的验收方 | 候选与证据绑定、独立反例；风险需要时重验 |

源码、测试、依赖、环境或契约改变后，相应旧结果失效。只有候选 SHA 一致不等于可复用。
本轮没有新增跨进程持久化测试缓存，不复用未经验证的主协调者自述。
Standard、Lite、docs-short 的门禁和真实用户验收边界不变。

## 规则与遥测

- 公共安全仍完整装载；角色上下文不再额外复制另一份可能漂移的六条摘要。
- 上下文 CLI 显式传 `--profile <已固化Profile>`，不依赖可能残留的环境默认值。它只渲染规则，不选择或持久化策略；未解析的 auto 或未知值拒绝使用。
- Reviewer、QA、Verifier 只返回结论；状态写入归主协调者或 Runner。旧 HOTFIX 标签不向模型授予免检或直接验收权限。旧 CLI 兼容行为未被本轮改写。
- Standard 受控 QA 命令与 Lite 测试每 15 秒产生等待心跳。心跳不包含原始输出、不运行命令，不改变超时、退出码或权限。遥测异常不构成通过或失败依据。
- Standard 命令结果与诊断证据保留 `duration_seconds`；Lite 完成事件报告耗时，返回命令诊断带耗时，不改变 Verifier 的规范化检查引用。当前未把每条 Lite 耗时单独持久化到 Verifier 证据。
- 命令仍使用既有安全校验和 subprocess 超时；恢复测试 Git 操作及子解释器补齐超时。
- 不声称已经实现所有命令的进程树清理、原生客户端进度插件或跨进程测试缓存。原生 Cursor 的等待展示是编排规约，Runner 命令心跳是确定性实现。

## 后续优化的安全边界

下一轮若要优化 Git 测试夹具，可建立只读种子并给每例独立复制，必须先证明项目根、锁、证据、候选与工作区互不污染。
不默认并行全部用例；端口、环境变量和导出路径隔离之前不得开启全量并行。
保留失败用例，不通过重跑偶然通过关闭缺陷。
